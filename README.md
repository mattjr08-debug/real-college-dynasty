# Real College Dynasty

College Dynasty with real Division I schools instead of made-up ones.

- **GitHub:** https://github.com/mattjr08-debug/real-college-dynasty (private). First commit `ecade4f`, 2026-10-12.
- **Mac folder:** ~/Documents/Real College Dynasty
- **Data:** 365 real D-I schools in their 2026-27 conferences, real 2026-27 rosters (ESPN), 2025-26 stats (Torvik), estimated NIL budgets, 4,718 player photos, 365 logos. See `REAL-COLLEGE-NOTES.md`.
- **Engine:** the same engine as College Dynasty (https://github.com/mattjr08-debug/College-Dynasty). Engine changes are copied over by hand; the two repos are separate.
- **Not in git** (see `.gitignore`): `dist/`, `dist-app/`, `desktop/node_modules`, `desktop/game`, `_to_delete/`, `realdata/test`, `realdata/phone-pub`.
